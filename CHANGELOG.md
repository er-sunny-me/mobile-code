# Changelog

All notable changes to Novus IDE will be documented in this file.

## [1.3.0] - 2026-06-04

### ✅ COMPLETED (New in this release)
- **Real-Time Web Search Integration**: AI can now autonomously search the web using Firecrawl, Tavily, Brave, or Serper when it encounters unknown concepts or obscure errors.
- **Interactive `@` File Tagging**: Type `@` in chat to summon your project files and instantly inject them into the AI's context.
- **Token-Optimized Smart Error Solving**: Tap "Fix with AI" on a terminal error to automatically extract the precise file, line, and surrounding code snippet for a quick, accurate fix.
- **Advanced Repository Structure**: Overhauled CI/CD with GitHub actions, new documentation, and proper APK split naming (`Novus-IDE-v1.3.0-release.apk`).

### 🚧 IN PROGRESS (Coming Next Release)
- **Visual Git Integration**: Visual branching, committing, and pushing from the editor.
- **Database Explorer**: Integrated SQLite database viewer and editor.
- **Specialized AI Agents**: Background orchestration for complex, multi-step debugging tasks.

### 📋 PLANNED (v1.4.0+)
- **Cloud Sync**: Sync settings across devices.
- **Live Preview Web Server**: Instantly see HTML/React/Vue changes in an embedded WebView.
- **Full Plugin API**: Let users write JavaScript plugins to extend Novus IDE natively.

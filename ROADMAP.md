# 🗺️ Roadmap

Here is a glimpse of what's coming to Novus IDE in the future.

### Phase 1: AI Autonomy & Integration (Completed ✔️)
- Multi-provider AI support (OpenAI, Anthropic, Gemini, Groq, etc.)
- Autonomous Agent capability for scaffolding projects
- Token-optimized Error Solving
- Real-time Web Search Integration (Tavily, Firecrawl, Brave, Serper)
- `@` File Tagging for Context Injection

### Phase 2: Enhanced Editor & Cloud (In Progress 🚧)
- **Git UI Integration**: Visual branching, committing, and pushing from the editor.
- **MCP (Model Context Protocol) Support**: Expand AI capabilities with local plugins.
- **Cloud Sync**: Sync your IDE settings and `ai_settings` across devices.

### Phase 3: Premium Desktop Parity (Planned ⏳)
- **Multi-Split Editor Views**: Edit two files side by side on tablets/foldables.
- **Live Preview Web Server**: Instantly see HTML/React/Vue changes in an embedded WebView.
- **Full Plugin API**: Let users write JavaScript plugins to extend Novus IDE.
